# BIOVERT Website

Website landing page untuk BIOVERT, ekosistem bioenergi sirkular yang mengubah limbah organik menjadi energi.

## Cara menjalankan

Buka file `index.html` langsung di browser, atau jalankan server statis lokal di folder proyek seperti:

```bash
python -m http.server 8000
```

Lalu buka: http://localhost:8000

## Struktur file

- `index.html` — halaman utama website
- `styles.css` — styling premium dan responsif
- `script.js` — interaksi kecil seperti menu mobile dan reveal animation
